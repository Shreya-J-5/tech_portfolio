# React Portfolio

This portfolio was converted from the original single-file HTML version into a small React + Vite app without changing the design.

## Use it

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Build for production: `npm run build`

## Customize

Update the content in `src/App.jsx` to replace the placeholder text: name, role, pitch, projects, experience, stack, email and links.

- The CSS remains in `src/styles.css` so the visual design stays unchanged from the original.
- The animation and theme behavior are preserved in the React version.
